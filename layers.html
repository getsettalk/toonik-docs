Layers ​

Layers are like clear sheets stacked on top of each other. Put the background on one, a character on another, and you can redraw the character without touching the background. A project can have up to 15 layers.

Tap Layer in the bottom bar.

  • The layer at the top of the list is drawn on top.
  • Tap a layer to draw on it. Tap the selected layer's name to rename it.
  • ≡ handle — drag to change the order (or long-press the row and drag).
  • 👁 eye — hide or show the layer.
  • Pink + — add a new layer.
  • › — the layer's settings.

Swipe a layer to the left for Lock (stops any drawing on it), Merge (joins it with the layer below), Duplicate and Delete.

Layer settings ​

  • Name and Opacity.

  • Blending mode — how the layer mixes with the ones below: Normal, Multiply (great for shadows), Screen (light), Overlay, Darken, Lighten, Add, Color Dodge, Color Burn, Hard Light, Soft Light, Difference, Exclusion, Hue, Saturation, Color and Luminosity.

  • Alpha lock — paint only over what is already drawn on this layer. Perfect for shading inside the lines.

  • Clipping mask — show this layer only where the layer below has drawing. Put a pattern or shadow layer above a character and clip it.

  • Pixel effect — turns the layer into chunky pixels (choose the pixel size).

  • Glow — a soft glow around the drawing, with its own colour, size and strength.

  • Merge down — joins this layer with the one below. Undo brings both back. Duplicate and Delete are here too.

Deleting a layer removes it from every frame.
